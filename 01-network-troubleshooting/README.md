# Network Troubleshooting & Packet Tracer Labs

## Project Overview

This project documents my hands-on networking practice using Cisco Packet Tracer as part of my cybersecurity training with Per Scholas.

The labs cover fundamental networking concepts including IP addressing, MAC addresses, DHCP, NAT, wireless networking, network connectivity, routed networks, and common network services.

## Objectives

- Configure and troubleshoot basic networks
- Understand IPv4 addressing and network communication
- Configure wireless networking and DHCP
- Examine NAT and routed traffic
- Use basic network troubleshooting commands
- Understand common network services and protocols
- Verify connectivity between network devices

## Tools

- Cisco Packet Tracer
- IPv4
- DHCP
- NAT
- Ping
- ipconfig
- FTP
- Telnet
- SSH
- HTTP
